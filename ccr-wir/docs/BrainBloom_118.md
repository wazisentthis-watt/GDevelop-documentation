# BrainBloom 118
### 118 real skills. 1,000 ways to practice them. Built to make the world a little more brain healthy.

## The one rule everything else follows

A skill only makes this list if it passes four tests:

1. **Action** — something you can actually *do*, not just know about
2. **Proof** — a way to show you did it
3. **Progress** — performance that can measurably improve
4. **Transfer** — it helps you somewhere outside the game

"Learn about elephants" is knowledge. "Read five elephant warning signals from posture alone" is a skill. Everything below is written the second way on purpose.

## How 118 becomes 1,000

Each of the 118 skills can be met in eight different forms:

**Discover → Practice → Recall → Apply → Create → Cooperate → Teach → Return**

118 × 8 = 944, plus 56 rare surprise encounters (more on those below) = **1,000 total experiences** from one list of real abilities.

## The five levels every skill moves through

| Level | Name | What it means |
|---|---|---|
| 0 | Unopened | Haven't tried it yet |
| 1 | First Contact | Complete it with heavy guidance |
| 2 | Assisted Use | Complete it with hints or correction |
| 3 | **Independent Use** | Complete it with no step-by-step help — **this is the level where it officially counts as learned** |
| 4 | Transfer | Apply it somewhere new |
| 5 | Teach or Create | Explain it, teach it, or build something original with it |

Nobody starts at zero for everything. A short **Discovery Run** — small trials across a handful of skills — checks what's already mastered and swaps it out, so the list is never padded with fake progress.

## The surprise encounters — "shocking Pokémon pop-ups," done on purpose

These are the 56 rare experiences layered on top of the 944. The whole point is that they interrupt like a wild creature bursting onto the screen, not like a notification demanding your attention.

- **Wild KoPani Appeared** — a creature tears in with a 10-second challenge: copy its rhythm, name its movement, finish its pattern. Rush it and it leaves. Earn a Petal by not rushing.
- **Memory Mimic** — a creature comes back using something you learned three days ago, with zero warning. You have to retrieve it, not relearn it.
- **Element Storm** — the whole interface briefly obeys one material relationship (Copper connects separated information, Sodium demands precise starts, Iron demands you carry something without dropping it).
- **Glitch KoPani** — gives you a convincing wrong answer. The reward is in catching it, not trusting it.
- **Golden Rest Encounter** — the challenge is to put the device down, look away, move, drink water, and come back later. Stopping on purpose earns real progress. This one is the whole philosophy in one encounter.
- **Mystery Egg** — an unidentified skill fragment. Only repeated encounters reveal which of the 12 domains it actually belongs to.
- **Rival Attuner** — an AI that learns differently than you do. Sometimes you race it, sometimes you teach it, sometimes its way turns out to just be better for this one problem.
- **Community Rescue** — a problem that needs several skills stacked at once: read the signal, calculate the route, fix the circuit, explain the fix clearly.

## One fully worked skill card, so the depth is visible

**Skill — Left-Hand Root**
Hold a steady bass rhythm with the left hand while the right hand plays a changing three-note phrase.

- **Baseline test:** can you hold both parts for ten seconds?
- **3-minute practice:** isolated left-hand loop, then layer the right hand in
- **AI coach:** flags rushing, uneven spacing, tension, dropped notes
- **Proof:** three clean passes at 70 BPM with no visual prompts
- **Transfer:** the same bilateral coordination shows up in typing, drumming, or game controls
- **Mastery:** counts as learned at Level 3 (independent, no prompts)

That's the model underneath all 118 — a real baseline, a short real practice, and real proof, every time.
