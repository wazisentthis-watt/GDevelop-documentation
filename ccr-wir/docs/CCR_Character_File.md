# CCR — Full Character File
### The complete 129-fighter roster, real builds, real computed stats

Crown / Core / Root are real periodic elements. MOV/PWR/HP are computed directly from real atomic data (electronegativity, ionization energy, density, atomic radius, conductivity, melting point, specific heat, hardness) — not hand-picked. Movement pattern is set by the Root element. Where a Crown+Core+Root trio forms a real known compound, that reaction is noted.
