Methodology: Crown = perception/heal element (sets Intel Tier). Core = attack/bond-chemistry element (sets Type-chart category). Root = movement/defense element (sets chess movement pattern). All three drawn only from CCR's 16 legal elements — where a character's established WIR lore referenced a real-world element outside that list (Ca, P, S, K, Cr, Ni, Mn, He, Ar, Ne, Kr, H, O, Hg, B, U, Ag, Zn, etc.), the nearest legal element by real chemical/physical property was substituted. Planet Nem's 12 Pride champions + Nemzo were built directly from their own declared elements in "The Twelve Declarations" wherever those elements are CCR-legal.
Stats: MOV/PWR/HP = Bible base (3/3/6) + 8 points, allocated by each fighter's two AA-based gameplay classes (4pts/class) — so the CCR build traces directly back to the NBD/AA layer, not a separate guess.
Self-compounds: a few builds land on a real playable compound using only their own three elements (e.g. Lyra Voss = W+F = WF₆, the highest damage multiplier in the game) — click a row to see it flagged.
Not yet done: cross-character bond-type math (ΔEN between two fighters' Core elements) is a runtime combat calc, not fixed per fighter — that resolves live in Arena, same as the Game Bible intends.
